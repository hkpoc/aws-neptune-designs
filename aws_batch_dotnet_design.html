AWS .NET Multi-Tenant Batch Architecture

Building a Spring Batch–style, KMS-aware, multi-tenant data purge engine in .NET on AWS.

1. Executive Summary & Architectural Vision

  • Multi-Tenant Configuration: Each tenant has custom retention windows, purge rules, schedules, and isolated or shared data stores.
  • Bimodal Workload Profile: Initial heavy backfill (millions of rows) vs. lightweight daily ongoing purges.
  • KMS Cryptographic Isolation: Tenant data is protected by AWS KMS. The engine must decrypt/verify without violating cross-tenant boundaries or hitting KMS rate limits.
  • Spring Batch Ergonomics in .NET: Requires chunk-based processing, cursor checkpointing, item-level skip/retry, and dead-letter logging natively in .NET 8.

Chunk-Oriented Executor (C#)

Demonstrating how to handle Spot interruptions smoothly via DynamoDB checkpointing.

public sealed class ChunkStepExecutor<TIn, TOut>(
    IChunkReader<TIn> reader,
    IItemProcessor<TIn, TOut> processor,
    IChunkWriter<TOut> writer,
    IJobRepository jobRepository,
    ILogger<ChunkStepExecutor<TIn, TOut>> logger)
{
    public async Task ExecuteStepAsync(TenantJobContext initialContext, CancellationToken ct)
    {
        // 1. Recover previous state from JobRepository (Restartability)
        var checkpoint = await jobRepository.GetOrCreateStepExecutionAsync(initialContext, ct);
        var currentContext = initialContext with { LastCursorToken = checkpoint.LastCursorToken };

        await foreach (var rawChunk in reader.ReadChunksAsync(currentContext, ct))
        {
            var processedBatch = new List<TOut>(rawChunk.Count);
            int skippedInChunk = 0;

            // 2. ItemProcessor phase
            foreach (var item in rawChunk)
            {
                try
                {
                    var result = await processor.ProcessAsync(item, currentContext, ct);
                    if (result is not null) processedBatch.Add(result);
                    else skippedInChunk++;
                }
                catch (PurgeSkippableException ex)
                {
                    skippedInChunk++;
                    await jobRepository.LogSkippedItemAsync(currentContext, item, ex.Message, ct);
                }
            }

            // 3. ItemWriter phase
            if (processedBatch.Count > 0)
            {
                string nextCursor = await writer.WriteChunkAsync(processedBatch, currentContext, ct);
                currentContext = currentContext with { LastCursorToken = nextCursor };
            }

            // 4. Commit Checkpoint
            await jobRepository.CommitChunkCheckpointAsync(
                jobExecutionId: currentContext.JobExecutionId,
                newCursorToken: currentContext.LastCursorToken,
                readCountDelta: rawChunk.Count,
                writeCountDelta: processedBatch.Count,
                skipCountDelta: skippedInChunk,
                ct: ct);
        }

        await jobRepository.MarkStepCompletedAsync(currentContext.JobExecutionId, ct);
    }
}
