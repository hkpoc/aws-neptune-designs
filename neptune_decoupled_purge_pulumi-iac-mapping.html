Pulumi IaC Step Functions + Batch (Fargate) + SQS Least-Privilege Roles

AWS → Pulumi IaC Mapping

Long-lived infrastructure is managed by Pulumi (TypeScript, @pulumi/aws v7). The ephemeral discovery clone is deliberately not a Pulumi resource. The Classic provider's aws.neptune.Cluster has no point-in-time or copy-on-write restore input (only snapshotIdentifier). Pulumi AWS Native (aws-native.neptune.DbCluster, which maps to AWS::Neptune::DBCluster) does expose restoreType, sourceDbClusterIdentifier and useLatestRestorableTime. Even so, a per-run clone doesn't belong in stack state, and you should never run pulumi up or pulumi destroy for each weekly run. Pulumi provisions everything the clone needs (IAM, subnet group, security group, parameter group). Step Functions creates and deletes the clone at runtime.

IAM model
  • Control plane: Neptune management APIs (restore, create, delete, describe) are authorized with rds:* actions. The Step Functions Resource ARN is still arn:aws:states:::aws-sdk:neptune:<action>. Delete actions are limited to clone-named ARNs, so the orchestrator can't delete a production cluster.
  • Discovery role: neptune-db:ReadDataViaQuery only. The clone's resource ID isn't known until runtime, so the grant is account- and Region-wide. It can only reach clusters whose security group admits the discovery security group, which is the clone SG alone.
  • Executor role: ReadDataViaQuery, DeleteDataViaQuery and GetQueryStatus on the configured production cluster-XXXX resource IDs only. Requests are SigV4-signed.

1. Pulumi Program (TypeScript, @pulumi/aws v7)

import * as pulumi from "@pulumi/pulumi";
import * as aws from "@pulumi/aws";
import * as fs from "fs";

const cfg = new pulumi.Config();
const vpcId = cfg.require("vpcId");
const privateSubnetIds = cfg.requireObject<string[]>("privateSubnetIds"); // same AZs as the source clusters
const prodClusterResourceIds = cfg.requireObject<string[]>("prodClusterResourceIds"); // cluster-XXXX
const region = aws.getRegionOutput().name;
const accountId = aws.getCallerIdentityOutput().accountId;
const prefix = "neptune-purge";

// ---------- DynamoDB: config, run ledger, chunk ledger, cluster leases ----------
const table = (name: string, hashKey: string, rangeKey?: string, ttlAttr?: string) =>
    new aws.dynamodb.Table(name, {
        name,
        billingMode: "PAY_PER_REQUEST",
        hashKey,
        rangeKey,
        attributes: [{ name: hashKey, type: "S" }, ...(rangeKey ? [{ name: rangeKey, type: "S" }] : [])],
        pointInTimeRecovery: { enabled: true },
        serverSideEncryption: { enabled: true },
        ttl: ttlAttr ? { attributeName: ttlAttr, enabled: true } : undefined,
    });
const tenantConfig = table("NeptuneTenantPurgeConfig", "TenantId");
const runLedger    = table("NeptunePurgeRunLedger", "TenantId", "RunId");
const chunkLedger  = table("NeptunePurgeChunkLedger", "RunKey", "ChunkId");
const clusterLease = table("NeptunePurgeClusterLease", "ClusterResourceId", undefined, "ExpiresAt");

// ---------- S3 manifest store ----------
const manifests = new aws.s3.Bucket("manifests", { bucketPrefix: `${prefix}-manifests-` });
new aws.s3.BucketPublicAccessBlock("manifests-pab", {
    bucket: manifests.id,
    blockPublicAcls: true, blockPublicPolicy: true, ignorePublicAcls: true, restrictPublicBuckets: true,
});
new aws.s3.BucketServerSideEncryptionConfiguration("manifests-sse", {
    bucket: manifests.id,
    rules: [{ applyServerSideEncryptionByDefault: { sseAlgorithm: "aws:kms" }, bucketKeyEnabled: true }],
});
new aws.s3.BucketLifecycleConfiguration("manifests-lc", {
    bucket: manifests.id,
    rules: [{ id: "expire-manifests", status: "Enabled", filter: {}, expiration: { days: 400 } }],
});

// ---------- SQS: edge phase, vertex phase, shared DLQ ----------
const FOURTEEN_DAYS = 1_209_600;               // default is 4 days; 14 days is the maximum
const dlq = new aws.sqs.Queue("chunk-dlq", {
    name: "NeptunePurgeChunkDLQ",
    messageRetentionSeconds: FOURTEEN_DAYS,    // >= source queues (expiry uses original enqueue time)
    sqsManagedSseEnabled: true,
});
const phaseQueue = (phase: "edge" | "vertex") => new aws.sqs.Queue(`${phase}-queue`, {
    name: `NeptunePurge${phase === "edge" ? "Edge" : "Vertex"}Queue`,
    messageRetentionSeconds: FOURTEEN_DAYS,
    visibilityTimeoutSeconds: 900,             // heartbeat with ChangeMessageVisibility (max 12h from receipt)
    receiveWaitTimeSeconds: 20,
    sqsManagedSseEnabled: true,
    redrivePolicy: dlq.arn.apply(arn => JSON.stringify({ deadLetterTargetArn: arn, maxReceiveCount: 3 })),
});
const edgeQueue = phaseQueue("edge");
const vertexQueue = phaseQueue("vertex");

// ---------- Networking & parameters for the runtime clone ----------
const discoverySg = new aws.ec2.SecurityGroup("discovery-sg", {
    vpcId, description: "Discovery workers",
    egress: [{ protocol: "-1", fromPort: 0, toPort: 0, cidrBlocks: ["0.0.0.0/0"] }],
});
const executorSg = new aws.ec2.SecurityGroup("executor-sg", {
    vpcId, description: "Purge executors (add to prod cluster SG ingress on 8182)",
    egress: [{ protocol: "-1", fromPort: 0, toPort: 0, cidrBlocks: ["0.0.0.0/0"] }],
});
const cloneSg = new aws.ec2.SecurityGroup("clone-sg", {
    vpcId, description: "Ephemeral Neptune discovery clones",
    ingress: [{ protocol: "tcp", fromPort: 8182, toPort: 8182, securityGroups: [discoverySg.id] }],
});
const cloneSubnets = new aws.neptune.SubnetGroup("clone-subnets", {
    name: `${prefix}-clone-subnets`, subnetIds: privateSubnetIds,
});
const cloneParams = new aws.neptune.ClusterParameterGroup("clone-params", {
    name: `${prefix}-clone-params`,
    family: "neptune1.4",                       // match the source engine family
    parameters: [{ name: "neptune_query_timeout", value: "3600000" }],
});

// ---------- ECR ----------
const repo = new aws.ecr.Repository("purge-images", {
    name: prefix, imageTagMutability: "IMMUTABLE",
    imageScanningConfiguration: { scanOnPush: true },
});

// ---------- IAM ----------
const assume = (svc: string) => JSON.stringify({
    Version: "2012-10-17",
    Statement: [{ Effect: "Allow", Principal: { Service: svc }, Action: "sts:AssumeRole" }],
});
const execRole = new aws.iam.Role("task-exec-role", { assumeRolePolicy: assume("ecs-tasks.amazonaws.com") });
new aws.iam.RolePolicyAttachment("task-exec-attach", {
    role: execRole.name,
    policyArn: "arn:aws:iam::aws:policy/service-role/AmazonECSTaskExecutionRolePolicy",
});

// Discovery: read-only graph access, no delete rights anywhere.
// The clone's resource ID is allocated at runtime, so scope by account/region; network isolation
// (clone SG admits only discoverySg) limits which clusters the role can actually reach.
const discoveryRole = new aws.iam.Role("discovery-role", { assumeRolePolicy: assume("ecs-tasks.amazonaws.com") });
new aws.iam.RolePolicy("discovery-policy", {
    role: discoveryRole.id,
    policy: pulumi.all([manifests.arn, edgeQueue.arn, vertexQueue.arn, chunkLedger.arn, runLedger.arn, region, accountId])
        .apply(([b, eq, vq, cl, rl, r, a]) => JSON.stringify({
            Version: "2012-10-17",
            Statement: [
                { Effect: "Allow", Action: ["neptune-db:ReadDataViaQuery"], Resource: `arn:aws:neptune-db:${r}:${a}:*/*` },
                { Effect: "Allow", Action: ["s3:PutObject"], Resource: `${b}/*` },
                { Effect: "Allow", Action: ["sqs:SendMessage"], Resource: [eq, vq] },
                { Effect: "Allow", Action: ["dynamodb:PutItem", "dynamodb:UpdateItem", "dynamodb:GetItem"], Resource: [cl, rl] },
            ],
        })),
});

// Executor: read + delete + query status on PRODUCTION cluster resource IDs only.
const executorRole = new aws.iam.Role("executor-role", { assumeRolePolicy: assume("ecs-tasks.amazonaws.com") });
new aws.iam.RolePolicy("executor-policy", {
    role: executorRole.id,
    policy: pulumi.all([manifests.arn, edgeQueue.arn, vertexQueue.arn, chunkLedger.arn, runLedger.arn,
                        clusterLease.arn, tenantConfig.arn, region, accountId])
        .apply(([b, eq, vq, cl, rl, lt, tc, r, a]) => JSON.stringify({
            Version: "2012-10-17",
            Statement: [
                { Effect: "Allow",
                  Action: ["neptune-db:ReadDataViaQuery", "neptune-db:DeleteDataViaQuery", "neptune-db:GetQueryStatus"],
                  Resource: prodClusterResourceIds.map(id => `arn:aws:neptune-db:${r}:${a}:${id}/*`) },
                { Effect: "Allow", Action: ["s3:GetObject"], Resource: `${b}/*` },
                { Effect: "Allow", Action: ["sqs:ReceiveMessage", "sqs:DeleteMessage", "sqs:ChangeMessageVisibility",
                    "sqs:GetQueueAttributes", "sqs:SendMessage"], Resource: [eq, vq] },
                // TransactWriteItems is authorized per item action (UpdateItem / ConditionCheckItem)
                { Effect: "Allow", Action: ["dynamodb:GetItem", "dynamodb:PutItem", "dynamodb:UpdateItem",
                    "dynamodb:ConditionCheckItem", "dynamodb:Query"], Resource: [cl, rl, lt, tc] },
                { Effect: "Allow", Action: ["cloudwatch:GetMetricData", "rds:DescribeDBClusters"], Resource: "*" },
            ],
        })),
});

// ---------- AWS Batch ----------
const fargateCe = (name: string, type: "FARGATE" | "FARGATE_SPOT", sg: aws.ec2.SecurityGroup) =>
    new aws.batch.ComputeEnvironment(name, {
        name: `${prefix}-${name}`,
        type: "MANAGED",
        computeResources: { type, maxVcpus: 64, subnets: privateSubnetIds, securityGroupIds: [sg.id] },
    });
const spotCe = fargateCe("discovery-spot", "FARGATE_SPOT", discoverySg);
const odCe = fargateCe("execution-od", "FARGATE", executorSg);

const jobQueue = (name: string, ce: aws.batch.ComputeEnvironment) => new aws.batch.JobQueue(name, {
    name: `${prefix}-${name}`, state: "ENABLED", priority: 1,
    computeEnvironmentOrders: [{ order: 1, computeEnvironment: ce.arn }],
});
const discoveryQueue = jobQueue("discovery", spotCe);
const executionQueue = jobQueue("execution", odCe);

const jobDef = (name: string, tag: string, role: aws.iam.Role, vcpu: string, memMiB: string, timeoutSec: number) =>
    new aws.batch.JobDefinition(name, {
        name: `${prefix}-${name}`,
        type: "container",
        platformCapabilities: ["FARGATE"],
        timeout: { attemptDurationSeconds: timeoutSec },
        retryStrategy: {
            attempts: 3,
            evaluateOnExits: [
                { onStatusReason: "Host EC2*", action: "RETRY" },    // Fargate Spot reclaim
                { onReason: "*", action: "EXIT" },
            ],
        },
        containerProperties: pulumi.all([repo.repositoryUrl, execRole.arn, role.arn])
            .apply(([url, exec, job]) => JSON.stringify({
                image: `${url}:${tag}`,
                executionRoleArn: exec,
                jobRoleArn: job,
                runtimePlatform: { operatingSystemFamily: "LINUX", cpuArchitecture: "X86_64" }, // Spot: no ARM64
                resourceRequirements: [{ type: "VCPU", value: vcpu }, { type: "MEMORY", value: memMiB }],
                networkConfiguration: { assignPublicIp: "DISABLED" },
                logConfiguration: { logDriver: "awslogs" },
            })),
    });
const DISCOVERY_TIMEOUT = 6 * 3600;             // the reaper must never key on age below this
const discoveryJob = jobDef("discovery", "discovery-1.1.0", discoveryRole, "2", "4096", DISCOVERY_TIMEOUT);
const executorJob = jobDef("executor", "executor-1.1.0", executorRole, "1", "2048", 7 * 3600);

// ---------- Step Functions (orchestrator + reaper) ----------
const sfnLogs = new aws.cloudwatch.LogGroup("sfn-logs", { name: `/aws/vendedlogs/states/${prefix}`, retentionInDays: 90 });
const sfnRole = new aws.iam.Role("sfn-role", { assumeRolePolicy: assume("states.amazonaws.com") });
new aws.iam.RolePolicy("sfn-policy", {
    role: sfnRole.id,
    policy: JSON.stringify({
        Version: "2012-10-17",
        Statement: [
            // Neptune management APIs authorize with the rds: prefix
            { Effect: "Allow", Action: ["rds:RestoreDBClusterToPointInTime", "rds:CreateDBInstance",
                "rds:DescribeDBClusters", "rds:DescribeDBInstances", "rds:AddTagsToResource",
                "rds:ListTagsForResource"], Resource: "*" },
            // Destructive actions only on clone-named resources
            { Effect: "Allow", Action: ["rds:DeleteDBInstance", "rds:DeleteDBCluster"],
              Resource: ["arn:aws:rds:*:*:cluster:neptune-clone-*", "arn:aws:rds:*:*:db:neptune-clone-*"] },
            { Effect: "Allow", Action: ["batch:SubmitJob", "batch:DescribeJobs", "batch:TerminateJob"], Resource: "*" },
            { Effect: "Allow", Action: ["events:PutTargets", "events:PutRule", "events:DescribeRule"], Resource: "*" },
            { Effect: "Allow", Action: ["dynamodb:Query", "dynamodb:GetItem", "dynamodb:PutItem",
                "dynamodb:UpdateItem", "dynamodb:DeleteItem"], Resource: "*" },
            { Effect: "Allow", Action: ["states:DescribeExecution"], Resource: "*" },   // reaper: owner still RUNNING?
            { Effect: "Allow", Action: ["logs:CreateLogDelivery", "logs:GetLogDelivery", "logs:UpdateLogDelivery",
                "logs:DeleteLogDelivery", "logs:ListLogDeliveries", "logs:PutResourcePolicy",
                "logs:DescribeResourcePolicies", "logs:DescribeLogGroups"], Resource: "*" },
        ],
    }),
});

const render = (file: string) => pulumi.all([tenantConfig.name, runLedger.name, chunkLedger.name, clusterLease.name,
        discoveryQueue.arn, discoveryJob.arn, executionQueue.arn, executorJob.arn,
        cloneSubnets.name, cloneSg.id, cloneParams.name, edgeQueue.url, vertexQueue.url])
    .apply(([tc, rl, cl, lt, dq, dj, eq, ej, sn, sg, pg, equ, vqu]) => fs.readFileSync(file, "utf8")
        .replace(/\$\{TenantTable\}/g, tc).replace(/\$\{LedgerTable\}/g, rl)
        .replace(/\$\{ChunkTable\}/g, cl).replace(/\$\{LeaseTable\}/g, lt)
        .replace(/\$\{DiscoveryQueue\}/g, dq).replace(/\$\{DiscoveryJobDef\}/g, dj)
        .replace(/\$\{ExecutionQueue\}/g, eq).replace(/\$\{ExecutorJobDef\}/g, ej)
        .replace(/\$\{CloneSubnetGroup\}/g, sn).replace(/\$\{CloneSg\}/g, sg)
        .replace(/\$\{CloneParamGroup\}/g, pg)
        .replace(/\$\{EdgeQueueUrl\}/g, equ).replace(/\$\{VertexQueueUrl\}/g, vqu));

const stateMachine = (name: string, file: string) => new aws.sfn.StateMachine(name, {
    name: `${prefix}-${name}`,
    type: "STANDARD",                            // runs last hours; Express caps at 5 minutes
    roleArn: sfnRole.arn,
    loggingConfiguration: { logDestination: pulumi.interpolate`${sfnLogs.arn}:*`, includeExecutionData: false, level: "ERROR" },
    definition: render(file),
});
const purgeSm = stateMachine("orchestrator", "orchestrator.asl.json");
const reaperSm = stateMachine("clone-reaper", "reaper.asl.json");

// ---------- EventBridge Scheduler ----------
const schedRole = new aws.iam.Role("scheduler-role", { assumeRolePolicy: assume("scheduler.amazonaws.com") });
new aws.iam.RolePolicy("scheduler-policy", {
    role: schedRole.id,
    policy: pulumi.all([purgeSm.arn, reaperSm.arn]).apply(arns => JSON.stringify({
        Version: "2012-10-17",
        Statement: [{ Effect: "Allow", Action: "states:StartExecution", Resource: arns }],
    })),
});
new aws.scheduler.Schedule("weekly-purge", {
    name: `${prefix}-weekly`,
    scheduleExpression: "cron(0 1 ? * SUN *)",
    scheduleExpressionTimezone: "UTC",
    flexibleTimeWindow: { mode: "OFF" },
    target: { arn: purgeSm.arn, roleArn: schedRole.arn, input: JSON.stringify({ mode: "PURGE" }) },
});
new aws.scheduler.Schedule("clone-reaper", {
    name: `${prefix}-clone-reaper`,
    scheduleExpression: "rate(1 hour)",
    flexibleTimeWindow: { mode: "OFF" },
    target: { arn: reaperSm.arn, roleArn: schedRole.arn, input: "{}" },
});

// ---------- CloudWatch alarms ----------
new aws.cloudwatch.MetricAlarm("dlq-not-empty", {
    namespace: "AWS/SQS", metricName: "ApproximateNumberOfMessagesVisible",
    dimensions: { QueueName: dlq.name },
    statistic: "Maximum", period: 300, evaluationPeriods: 1,
    threshold: 0, comparisonOperator: "GreaterThanThreshold", treatMissingData: "notBreaching",
});
new aws.cloudwatch.MetricAlarm("circuit-breaker", {
    namespace: "NeptunePurge/MultiTenant", metricName: "CircuitBreakerTripped",
    statistic: "Sum", period: 300, evaluationPeriods: 1,
    threshold: 3, comparisonOperator: "GreaterThanOrEqualToThreshold", treatMissingData: "notBreaching",
});
new aws.cloudwatch.MetricAlarm("uncertain-outcomes", {
    namespace: "NeptunePurge/MultiTenant", metricName: "RecordsUncertain",
    statistic: "Sum", period: 300, evaluationPeriods: 1,
    threshold: 0, comparisonOperator: "GreaterThanThreshold", treatMissingData: "notBreaching",
});

export const orchestratorArn = purgeSm.arn;
export const reaperArn = reaperSm.arn;
export const manifestBucket = manifests.bucket;
export const edgeQueueUrl = edgeQueue.url;
export const vertexQueueUrl = vertexQueue.url;

2. Step Functions Clone Lifecycle (ASL excerpt, JSONPath)

The clone lifecycle from section 4.1 of the v2.2 design. ${...} placeholders are filled in by the Pulumi program above. AWS SDK integrations take PascalCase parameter names in the SDK's own casing (DbClusterIdentifier, EnableIamDatabaseAuthentication), which differs from the API reference's DBClusterIdentifier.

"PreflightSource": {
  "Type": "Task",
  "Resource": "arn:aws:states:::aws-sdk:neptune:describeDBClusters",
  "Parameters": { "DbClusterIdentifier.$": "$.tenant.SourceClusterIdentifier" },
  "ResultSelector": {
    "Status.$": "$.DbClusters[0].Status",
    "LatestRestorableTime.$": "$.DbClusters[0].LatestRestorableTime"
  },
  "ResultPath": "$.source",
  "Next": "SourceRestorable?"
},
"SourceRestorable?": {
  "Type": "Choice",
  "Choices": [{
    "And": [
      { "Variable": "$.source.Status", "StringEquals": "available" },
      { "Variable": "$.source.LatestRestorableTime", "IsPresent": true },
      { "Not": { "Variable": "$.source.LatestRestorableTime", "IsNull": true } }
    ],
    "Next": "CreateClone"
  }],
  "Default": "FailPreflight"                 // never fall back to a full-copy restore
},
"CreateClone": {
  "Type": "Task",
  "Resource": "arn:aws:states:::aws-sdk:neptune:restoreDBClusterToPointInTime",
  "Parameters": {
    "SourceDbClusterIdentifier.$": "$.tenant.SourceClusterIdentifier",
    "DbClusterIdentifier.$": "$.cloneClusterId",          // deterministic: neptune-clone-{tenant}-{run}
    "RestoreType": "copy-on-write",
    "UseLatestRestorableTime": true,
    "EnableIamDatabaseAuthentication": true,               // API default is false
    "DeletionProtection": false,
    "DbSubnetGroupName": "${CloneSubnetGroup}",
    "VpcSecurityGroupIds": ["${CloneSg}"],
    "DbClusterParameterGroupName": "${CloneParamGroup}",

      { "Key": "Purpose", "Value": "NeptunePurgeDiscovery" },
      { "Key": "RunId", "Value.$": "$.runId" },
      { "Key": "SourceClusterId", "Value.$": "$.tenant.SourceClusterIdentifier" },
      { "Key": "OwnerExecution", "Value.$": "$$.Execution.Id" }
    ]
  },
  "ResultPath": "$.clone",
  "Retry": [{ "ErrorEquals": ["Neptune.InsufficientDbClusterCapacityException"], "MaxAttempts": 3, "BackoffRate": 2 }],
  "Catch": [
    { "ErrorEquals": ["Neptune.DbClusterAlreadyExistsException"], "ResultPath": "$.error", "Next": "WaitClusterAvailable" },
    { "ErrorEquals": ["States.ALL"], "ResultPath": "$.error", "Next": "CleanupClone" }
  ],
  "Next": "WaitClusterAvailable"
},
"WaitClusterAvailable": { "Type": "Wait", "Seconds": 60, "Next": "DescribeCloneCluster" },
"DescribeCloneCluster": {
  "Type": "Task",
  "Resource": "arn:aws:states:::aws-sdk:neptune:describeDBClusters",
  "Parameters": { "DbClusterIdentifier.$": "$.cloneClusterId" },
  "ResultSelector": { "Status.$": "$.DbClusters[0].Status" },
  "ResultPath": "$.cloneStatus",
  "Next": "ClusterReady?"
},
"ClusterReady?": {
  "Type": "Choice",
  "Choices": [{ "Variable": "$.cloneStatus.Status", "StringEquals": "available", "Next": "CreateCloneInstance" }],
  "Default": "WaitClusterAvailable"           // bound with a loop counter or state-level TimeoutSeconds
},
"CreateCloneInstance": {
  "Type": "Task",
  "Resource": "arn:aws:states:::aws-sdk:neptune:createDBInstance",
  "Parameters": {
    "DbClusterIdentifier.$": "$.cloneClusterId",
    "DbInstanceIdentifier.$": "States.Format('{}-i1', $.cloneClusterId)",
    "DbInstanceClass.$": "$.tenant.CloneComputeConfig.InstanceClass",
    "Engine": "neptune"
  },
  "ResultPath": "$.cloneInstance",
  "Catch": [{ "ErrorEquals": ["States.ALL"], "ResultPath": "$.error", "Next": "CleanupClone" }],
  "Next": "WaitInstanceAvailable"
},
// ... WaitInstanceAvailable / DescribeDBInstances loop, then:
"RunDiscovery": {
  "Type": "Task",
  "Resource": "arn:aws:states:::batch:submitJob.sync",
  "Parameters": {
    "JobQueue": "${DiscoveryQueue}",
    "JobDefinition": "${DiscoveryJobDef}",
    "JobName.$": "States.Format('discovery-{}', $.tenant.TenantId)",
    "ContainerOverrides": { "Environment": [
      { "Name": "CLONE_ENDPOINT", "Value.$": "$.cloneEndpoint" },
      { "Name": "RUN_KEY", "Value.$": "$.runKey" },
      { "Name": "CUTOFF_EPOCH", "Value.$": "States.Format('{}', $.cutoffEpoch)" }
    ]}
  },
  "ResultPath": "$.discovery",
  "Catch": [{ "ErrorEquals": ["States.ALL"], "ResultPath": "$.error", "Next": "CleanupClone" }],

}
// CleanupClone: deleteDBInstance → wait/describe until gone → deleteDBCluster { "SkipFinalSnapshot": true }
//               → wait/describe until DbClusterNotFoundFault → persist CloneCleanupStatus → route on $.error

Before deploying, validate with aws stepfunctions validate-state-machine-definition and a test execution against a disposable cluster. Pulumi resource and property names target @pulumi/aws v7. The Pulumi Registry lookup was only partly available during this review (neptune.Cluster, scheduler.Schedule and batch.ComputeEnvironment were verified), so run pulumi preview and tsc before deploying.
